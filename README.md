**Password generator and validator (Python)** 
About the project :-
This is a Python-based password validation program that checks whether a password meets specific security requirements. 
Features :-
Checks for at least one uppercase letter.
Checks for alphabetical characters from different keyboard rows. 
Checks for at least one digit 0-9. 
Checks for at least one lowercase letter.
Checks for at least one special character.
 Displays messages if any requirement is missing. 
 
 
 How to run :-
 Download or clone this repository. 
Open the project in VS Code. 
Run password_generated.py 
Enter your password when prompted. 
Check the validation messages.
